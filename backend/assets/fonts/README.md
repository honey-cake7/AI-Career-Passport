# PDF fonts

Noto Sans Regular, Bold and Italic are bundled for deterministic PDF output, including Latin extended, Greek, Cyrillic and common punctuation. These files do not cover every writing system; full multilingual export remains a release gate.

Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

License: SIL Open Font License 1.1, reproduced in `OFL.txt`. No runtime font downloads are required. Keep this directory alongside `dist` in the backend deployment.
